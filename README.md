# 🌙 Eid-ul-Adha Mubarak - Interactive Islamic Experience Website

A modern, cinematic, and animated Eid-ul-Adha themed web experience built with **Next.js, Tailwind CSS, and Framer Motion**.  
This project beautifully combines Islamic storytelling, animations, and educational content about **Qurbani (sacrifice)** in an interactive UI.

## 📌 Features

### 🌙 Hero Section
- Fullscreen Eid-ul-Adha Mubarak greeting
- Animated moon, stars, and floating particles
- Islamic aesthetic background
- Animated call-to-action button

### 🐐 Animated Animals Section
- Goat 🐐, Cow 🐄, Sheep 🐑, Camel 🐪
- Smooth hover & floating animations
- Islamic messages about kindness to animals

### 📖 Qurbani Information
- What is Qurbani?
- Importance in Islam
- Story of Prophet Ibrahim (A.S)
- Sunnah explanation
- Ethical sacrifice guidelines

### 🎬 Storytelling Page (/story)
- Cinematic scroll-based storytelling
- Prophet Ibrahim (A.S) story
- Dream of sacrifice
- Submission to Allah’s command
- Replacement with a sheep
- Emotional animated transitions

### ✨ UI/UX Features
- Glassmorphism design
- Dark Islamic theme (gold + midnight colors)
- Fully responsive (mobile + desktop)
- Smooth page transitions
- Scroll animations
